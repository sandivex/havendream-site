About

havenDream creates semi-realistic 3D props for farming and survival-style games: rustic wood textures, game-ready scale, Unity URP materials. Each asset starts from an AI-assisted base model, then is corrected, textured, and packaged for production use.

Our pipeline

havenDream is an independent asset studio focused on rustic, semi-realistic props for farming, ranch, and survival games. We build each piece to drop straight into a Unity URP project: correct scale, clean materials, and multiple state variants where it makes sense (empty, filled, weathered). Our pipeline blends AI-assisted base generation with additional modeling, texturing, and testing in Unity before anything ships.
